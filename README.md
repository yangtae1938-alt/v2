# 찍찍 하따레이더 v2.0

## 포함
- 급등 전 후보 정렬: 일봉 RVOL, 5일 압축, 20일 고점 접근, 추세, 유동성, 과열 감점
- 선택형 장중 5분봉 누적 거래량 비교
- SEC 최근 공시 및 희석 키워드의 제한적 자동 탐지
- 기술점수와 SEC 공시 페널티를 분리 표시
- 직접 티커 입력 또는 CSV 업로드, 결과 CSV 다운로드

## 배포
1. ZIP을 풀고 `app.py`, `requirements.txt`, `README.md`를 GitHub 저장소 최상위에 업로드합니다.
2. https://share.streamlit.io/ 에서 GitHub로 로그인합니다.
3. Create app에서 저장소, `main`, Main file path `app.py`를 선택하고 배포합니다.

## 주의
입력/CSV 티커만 스캔합니다. 미국 전체 종목 전수 검색, 완전한 장중 실시간 데이터, SEC 계약의 법적/정량적 희석 판정은 포함하지 않습니다. SEC 키워드는 단서일 뿐이므로 EFFECT, 등록서류, 계약조건, 잔여 한도, 전환가/워런트, 실제 발행주식 수를 원문에서 확인해야 합니다. 데이터는 지연/누락될 수 있으며 점수는 급등 확률이나 매수 추천이 아닙니다.
